# dsh-wsl-picker
> **Install set:** part of [dsh-wsl-kit](https://github.com/173787247/dsh-wsl-kit). Prefer `KIT_SET=daily` | `llm` | `github` | `full` (see kit README). Fault tree: [TROUBLESHOOTING.md](https://github.com/173787247/dsh-wsl-kit/blob/master/docs/TROUBLESHOOTING.md).


DeepSeek Harness plugin: Browse WSL directories from / and /mnt Windows drives for workspace picking.

Part of **[dsh-wsl-kit](https://github.com/173787247/dsh-wsl-kit)**.

[中文说明 → README.zh.md](./README.zh.md)

## Where it sits

Lists WSL directories under / and /mnt so a workspace can be picked. It does not register IM workspaces.

```mermaid
flowchart LR
  agent["dsh agent"] --> tool["wsl_picker"] --> fs["/ and /mnt listings"]
```

Suite diagram and version snapshot: [dsh-wsl-kit](https://github.com/173787247/dsh-wsl-kit#how-the-pieces-fit). This plugin is **0.1.0** (full). Do not copy that matrix into this README.

## Install

```sh
dsh plugin --profile web add github:173787247/dsh-wsl-picker
# or local:
dsh plugin --profile web add /absolute/path/to/dsh-wsl-picker
```

Restart `dsh web` and open a **new** session. Tool: `wsl_picker`.
